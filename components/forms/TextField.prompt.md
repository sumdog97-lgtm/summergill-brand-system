Square text input or textarea — use for any free-text entry.

```jsx
<TextField placeholder="e.g. Sam — Sam’s Barbershop" />
<TextField multiline rows={2} placeholder="Anything else worth knowing? (optional)" />
```

Placeholders are concrete, friendly examples ("e.g. …"), not labels. No visible labels — the mono "Step N · …" eyebrow above acts as the label.
