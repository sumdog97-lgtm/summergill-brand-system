The Summergill line-icon set (WhatsApp, check, arrow, shield…) — use anywhere an icon is needed; never mix in other icon libraries.

```jsx
<Icon name="whatsapp" size={20} />
<Icon name="check" size={16} style={{ color: 'var(--color-brand-soft)' }} />
```

- Names: whatsapp, check, arrow, spark, shield, pencil, rocket, bolt, phone, burger, close.
- Colour via `currentColor`. Sizes 16 / 20 / 24.
- In solid cobalt squares (44×44) for guarantee items — see `GridCell` `icon` prop.
