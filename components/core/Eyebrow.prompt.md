Mono uppercase section eyebrow — put above every section heading, numbered "NN / Label".

```jsx
<Eyebrow>02 / Our work</Eyebrow>
<Eyebrow tone="dark">03 / Pricing</Eyebrow>
<Eyebrow bracket>Hand-built websites · UK based</Eyebrow>
```

Sections are numbered sequentially (01 / The problem … 08 / Start the conversation).
