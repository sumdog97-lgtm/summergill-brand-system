The hairline grid of square cells — Summergill's only "card" treatment; use for any set of 2–4 parallel points.

```jsx
<GridPanel columns={3}>
  <GridCell title="Invisible on Google">When someone local searches…</GridCell>
</GridPanel>
<GridPanel columns={2}><GridCell icon="shield" title="Your domain, your content. Always.">…</GridCell></GridPanel>
<GridPanel columns={3}><GridCell number="01" title="Chat">…</GridCell></GridPanel>
```

No shadows, no radii. Cells sit on paper inside a 1px ink/15 rule.
